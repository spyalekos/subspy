# SubsPy - Διαχείριση Εσόδων & Εξόδων

  <img src="src/assets/icon_new.png" alt="SubsPy Logo" width="128"/>

Αγγλική έκδοση του README υπάρχει στο [english.md](english.md).

Εφαρμογή διαχείρισης εσόδων και εξόδων, κατασκευασμένη με **Python** και **Flet**.
Τρέχει σε Windows, macOS, Linux, Raspberry Pi και Android.

## Χαρακτηριστικά

- 📋 **Καταχωρήσεις** — Προσθήκη, επεξεργασία και διαγραφή εσόδων/εξόδων.
- 📅 **Επαναλαμβανόμενες κινήσεις** — Συνδρομές, μισθοί και περιοδικές κινήσεις (π.χ. μηνιαίες ή ανά προσαρμοσμένο αριθμό ημερών).
- 📊 **Αναφορές & Προοδευτικά Υπόλοιπα** — Υπολογισμός προοδευτικών χρεώσεων και υπολοίπων για οποιοδήποτε χρονικό διάστημα.
- 📄 **Εξαγωγή PDF** — Έγχρωμη αναφορά σε PDF (πράσινο = έσοδα, κόκκινο = έξοδα) με ανάλυση υπόλοιπου.
- 🏷️ **Κατηγορίες** — Οργάνωση κινήσεων σε προσαρμοσμένες κατηγορίες.
- 💾 **Backup & Restore** — Εξαγωγή και εισαγωγή όλων των δεδομένων σε JSON.
- 🔎 **Πλήρες & Άμεσο Zoom** — Πλήκτρα άμεσου ζουμ (+ / - / κλικ για επαναφορά στο 100%), καθώς και αναλογικό zoom με `Ctrl` + ρόδα ποντικιού.
- 📐 **Δυναμικοί Πίνακες** — Οι στήλες καταλαμβάνουν όλο το πλάτος της οθόνης, με μόνιμη οριζόντια μπάρα κύλισης στο κάτω μέρος όταν απαιτείται.
- ❔ **Ενσωματωμένη Βοήθεια** — Ευρύχωρο παράθυρο οδηγιών στα Ελληνικά και Αγγλικά.
- 🖼️ **Native Splash Screen** — Άμεση οθόνη έναρξης με το νέο λογότυπο ποδηλάτου με ρόδες νομισμάτων (€ / $).
- 🌍 **Πολυγλωσσία** — Πλήρες περιβάλλον στα Ελληνικά και στα Αγγλικά.
- 🖥️ **Cross-platform** — Υποστήριξη Windows, macOS, Linux, Raspberry Pi και Android.

Για να εκτελέσετε την εφαρμογή, κατεβάστε το έτοιμο εκτελέσιμο αρχείο της πιο πρόσφατης έκδοσης (π.χ. `subspy.exe` για Windows) από τη σελίδα των [Releases](https://github.com/spyalekos/subspy/releases) του αποθετηρίου και εκτελέστε το απευθείας, χωρίς καμία ανάγκη εγκατάστασης πρόσθετων βιβλιοθηκών.

## Χρήση

### 📋 Καταχωρήσεις
- Πατήστε **«+ Προσθήκη»** στην επάνω μπάρα για νέα εγγραφή.
- Επιλέξτε **Έσοδο** ή **Έξοδο** από τον επιλογέα τύπου.
- Ορίστε ημερομηνία, περιγραφή, ποσό, κατηγορία και συχνότητα επανάληψης.
- Πατήστε σε οποιαδήποτε γραμμή του πίνακα για επεξεργασία ή διαγραφή.
- Επανάληψη: `0` = μοναδική κίνηση, `30` = μηνιαία, `365` = ετήσια.

### 📊 Αναφορές
1. Μεταβείτε στην καρτέλα **«Αναφορές»**.
2. Επιλέξτε ημερομηνίες έναρξης («Από») και λήξης («Έως»).
3. Πατήστε **«Δημιουργία»** για εμφάνιση των κινήσεων και του προοδευτικού υπολοίπου.
4. Πατήστε **«Εκτύπωση PDF»** για άμεση δημιουργία και προβολή του αρχείου αναφοράς.

### 🛠️ Εργαλεία
- **Εξαγωγή**: Αποθηκεύει το σύνολο των εγγραφών και κατηγοριών σε αρχείο αντιγράφου ασφαλείας JSON.
- **Εισαγωγή**: Επαναφέρει τις εγγραφές από προηγούμενο αρχείο JSON.
- **Κατηγορίες**: Προσθήκη νέων και διαγραφή υπαρχουσών κατηγοριών.

### 🔍 Χειριστήρια Zoom & Βοήθεια
- **Zoom In / Out**: Χρησιμοποιήστε τα κουμπιά **+** και **-** στην επάνω μπάρα ή κρατήστε πατημένο το πλήκτρο `Ctrl` και περιστρέψτε τη ρόδα του ποντικιού.
- **Επαναφορά Zoom**: Πατήστε απευθείας στο ποσοστό zoom (π.χ. **100%**) για άμεση επαναφορά στην αρχική διάσταση.
- **Οδηγίες**: Πατήστε το εικονίδιο **?** στην επάνω δεξιά περιοχή για αναλυτικές οδηγίες χρήσης.

## Αποθήκευση Δεδομένων

| Πλατφόρμα | Τοποθεσία Βάσης Δεδομένων (`subscriptions.db`) |
|-----------|------------------------------------------------|
| Windows | Δίπλα στο αρχείο `subspy.exe` |
| Linux / Raspberry Pi | `~/subscriptions.db` |
| macOS | `~/Library/Application Support/SubsPy/subscriptions.db` |
| Android | Εσωτερικός ιδιωτικός χώρος εφαρμογής |
